## 🗂️ What Each Assignment Contains

Every subject folder follows the same clean pattern:

```
📁 Subject Name/
 ├── 📄 question.md      ← all questions (each linked to its answer)
 ├── 📄 answer1.md       ← answer to question 1
 ├── 📄 answer2.md       ← answer to question 2
 └── ...                 ← one file per question
```

### ✨ Every Answer Includes

1. Problem Understanding
2. Key Concepts (with tables)
3. Step-by-step Algorithm
4. Full Source Code
5. Line-by-line Explanation
6. Dry Run
7. Sample Input / Output
8. Edge Cases
9. Common Mistakes to Avoid
10. Alternative Versions
11. Summary Table for the Lab Record

## 🚀 Quick Start

1. **Tap your year** in the navigation above.
2. **Tap your semester**.
3. **Tap your assignment** — it opens the `question.md`.
4. **Tap any question** to open its answer instantly.

> 💡 Tip: Bookmark the folder of your current semester for super-fast access.
